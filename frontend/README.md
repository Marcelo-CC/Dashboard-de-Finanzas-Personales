# Frontend — Dashboard de Finanzas Personales

SPA en React 19 + Vite. Consulta el README principal del repositorio para la instalación completa.

```bash
npm install
cp .env.example .env   # VITE_API_URL=http://localhost:3000/api
npm run dev            # http://localhost:5173
npm run build          # compilación de producción en dist/
```
